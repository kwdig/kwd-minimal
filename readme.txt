白背景のコンパクトなクラシックテーマ。外部ライブラリ・外部フォントは使用しません。
紹介：https://kwdig.com/kwd-minimal
デモ：https://kwdig.com/kwd-minimal/demo/
ソース：https://github.com/kwdig/kwd-minimal

導入
1. WordPress管理画面の「外観 → テーマ → 新しいテーマを追加 → テーマのアップロード」で
   kwd-minimal-1.0.37.zip を選択し「今すぐインストール」、続いて「有効化」。
2. 「設定 → 一般」でサイト名、「設定 → 表示設定」で一覧の表示件数を設定。
   トップを記事一覧にする場合は「最新の投稿」を選択。
3. 「外観 → メニュー」でメニューを作成し、表示位置「ハンバーガーメニュー」に割り当て。
   未設定時はホームと固定ページを表示します。検索はこのメニュー内に常設されます。
4. 2カラムにする場合は「外観 → ウィジェット」の「右サイドバー（広告300×300対応）」へ
   ブロックを追加。画像ブロックまたはカスタムHTMLで300×300の広告を配置できます。
   検索ブロックは追加不要です。サイドバーを空にすると本文640px中央寄せになります。

仕様
・PCは本文最大640px、間隔20px、サイドバー320px。サイドバー内は左右10pxで広告実幅300px。
・画面幅1000px以下では1カラム。設定済みサイドバーは本文の下に、本文と同じ幅で表示。
・ヘッダー直下とフッター直上は1px罫線、上下余白16px。
・ブログタイトルのみ明朝。本文はゴシック16px・行間1.75・文字色#202122。
  記事タイトル24px、本文H1 22px、H2 18px、H3 16px。本文H1・H2には薄い区切り線。
  明朝・ゴシックは端末の搭載フォントを使用。本文H1は複数利用できます。
・投稿一覧、検索結果、アーカイブはul/liのタイトルリンクのみ。
・一覧は通常のページ番号と「前へ」「次へ」で移動します。一覧の表示件数はWordPress設定に従います。
・サイドバーの文字とH2見出しは参照FC2サイトに合わせ11.7px。見出しの色#767676・通常の太さは維持。
・投稿末尾に関連記事を最大10件表示。同カテゴリーの新着を優先し、足りなければほかの新着で補完。
  公開済み通常投稿のみ。現在の記事とパスワード保護された関連記事は除外。記事が少なければ10件未満。
  パスワード保護中の本文では関連記事を表示しません。固定ページには関連記事を表示しません。
・日付、投稿者、タグ・カテゴリーのメタラベル、前後記事ナビは出力しません。
  パンくずにはカテゴリー名と親カテゴリーを表示します。
・WordPress標準のコメント・記事内改ページ・固定ページ・パスワード保護・管理バーに対応。
  コメントを使わない場合は「設定 → ディスカッション」と各投稿のコメント設定を無効化。
  コメント内の投稿者・日時はWordPress標準表示です。記事本文やウィジェットに手動で入れた情報はそのまま表示。
・キーボード対応メニュー、Escapeで閉じる、スキップリンク、フォーカス表示。

メタディスクリプションの仕様と設定方法

v1.0.36から、ページの概要を検索エンジンへ伝えるメタディスクリプションに対応しています。記事本文中には表示されません。基本は自動生成で、必要なページだけ手動設定できます。外部AIやAPIは使用しません。

ページごとの出力ルール

・投稿・固定ページ：手動の説明文 → 手動の抜粋 → 本文からの自動抜粋
・トップページ：最新の投稿：トップ用の説明文 → サイトのキャッチフレーズ
・トップページ：固定ページ：その固定ページの説明文 → 抜粋 → 本文
・別に指定した投稿一覧ページ：投稿一覧用の説明文 → サイトのキャッチフレーズ
・カテゴリー・タグ一覧：管理画面の「説明」欄のみ。空欄なら出力しません
・著者・日付別一覧、検索結果、404：出力しません
・パスワード保護記事：出力しません

本文からの生成にはWordPress標準の get_the_excerpt() を使います。手動の抜粋があればそれを使用し、なければ本文から生成します。HTMLタグ・余分な空白・末尾の […] を除き、手動入力した説明文も含めて最大120文字に整えます。内容が空になった場合は、空のmetaタグも出力しません。

1．投稿・固定ページに説明文を設定する

1. 管理画面の「投稿」または「固定ページ」で、対象の記事を編集します。
2. 編集画面の 「メタディスクリプション」欄に、そのページを紹介する文章を入力します。
3. 記事を保存または更新します。入力した説明文が、抜粋・本文より優先されます。

空欄にして保存すると、抜粋・本文からの生成に戻ります。同じ欄には、保存済みの抜粋・本文から作る説明文の生成例も表示します。既存のカスタムフィールド _kwd_meta_description の値も引き継ぎます。

入力例：

  KWD Minimalの特徴と設定方法を紹介。レイアウト、メニュー、ウィジェットの使い方、ダウンロードと導入手順をまとめます。

2．抜粋を使って説明文を整える

個別の説明文を入力せずに調整したい場合は、記事編集画面の 「抜粋」欄に短い紹介文を入力します。固定ページでも抜粋を利用できます。「メタディスクリプション」欄が空なら、この抜粋が使われます。

3．トップ・投稿一覧の説明文を設定する

1. 「外観 → カスタマイズ → メタディスクリプション」を開きます。
2. 「トップページ（最新の投稿）の説明文」、または「別に指定した投稿一覧ページの説明文」を入力します。
3. カスタマイズ画面の 「公開」を押して設定を保存します。

空欄なら「設定 → 一般」の キャッチフレーズを使用します。キャッチフレーズも空なら出力しません。固定ページをトップに指定している場合は、ここに入力したトップ用説明文ではなく、その固定ページの説明文・抜粋・本文を使用します。

4．カテゴリー・タグの説明文を設定する

「投稿 → カテゴリー」または「投稿 → タグ」で対象を編集し、「説明」欄に文章を入力して更新します。そのカテゴリー・タグの一覧ページに使用します。説明欄が空の場合、カテゴリー名・タグ名などからの補完は行いません。

SEOプラグインの併用と出力の停止

Yoast SEO、Rank Math、All in One SEO、SEOPress、The SEO Frameworkを検出すると、テーマからの出力を止め、プラグイン側へ任せます。

別の方法で説明文を出力する場合や、テーマの機能を使わない場合は、「外観 → カスタマイズ → メタディスクリプション」の 「テーマから説明文を出力する」のチェックを外し、「公開」で保存してください。

自動生成の扱い

自動生成は文章の要約ではなく、抜粋の取り出しです。表の項目名・コード・一覧の文字を含む場合や、120文字の上限で文章の途中までになる場合があります。紹介文を整えたいページでは、手動の説明文または抜粋を設定してください。元の記事本文や表を自動で書き換えることはありません。

検索結果の説明文は検索エンジンが判断するため、設定した文章が必ずそのまま表示されるわけではありません。


注意
テーマ切り替え前にバックアップを取り、広告・既存プラグインとの表示を確認してください。
テーマの直接編集は更新時に上書きされるため、継続的なカスタマイズには子テーマを推奨します。
広告スクリプトは広告サービスが案内するコードを利用してください。
カスタムHTMLのscript保存可否はWordPressの権限・マルチサイト設定に従います。
