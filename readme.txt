白背景のコンパクトなクラシックテーマ。外部ライブラリ・外部フォントは使用しません。
紹介：https://kwdig.com/kwd-minimal
デモ：https://kwdig.com/kwd-minimal/demo/
ソース：https://github.com/kwdig/kwd-minimal

導入
1. WordPress管理画面の「外観 → テーマ → 新しいテーマを追加 → テーマのアップロード」で
   kwd-minimal-1.0.31.zip を選択し「今すぐインストール」、続いて「有効化」。
2. 「設定 → 一般」でサイト名、「設定 → 表示設定」で一覧の表示件数を設定。
   トップを記事一覧にする場合は「最新の投稿」を選択。
3. 「外観 → メニュー」でメニューを作成し、表示位置「ハンバーガーメニュー」に割り当て。
   未設定時はホームと固定ページを表示します。検索はこのメニュー内に常設されます。
4. 2カラムにする場合は「外観 → ウィジェット」の「右サイドバー（広告300×300対応）」へ
   ブロックを追加。画像ブロックまたはカスタムHTMLで300×300の広告を配置できます。
   検索ブロックは追加不要です。サイドバーを空にすると本文640px中央寄せになります。

仕様
・PCは本文最大640px、間隔20px、サイドバー320px。サイドバー内は左右10pxで広告実幅300px。
・画面幅1000px以下では1カラム。設定済みサイドバーは本文の下に表示。
・ヘッダー直下とフッター直上は1px罫線、上下余白16px。
・ブログタイトルのみ明朝。本文はゴシック16px・行間1.75・文字色#202122。
  記事タイトル24px、本文H1 22px、H2 18px、H3 16px。本文H1・H2には薄い区切り線。
  明朝・ゴシックは端末の搭載フォントを使用。本文H1は複数利用できます。
・投稿一覧、検索結果、アーカイブはul/liのタイトルリンクのみ。
・一覧は通常のページ番号と「前へ」「次へ」で移動します。一覧の表示件数はWordPress設定に従います。
・サイドバーの文字とH2見出しは参照FC2サイトに合わせ11.7px。見出しの色#767676・通常の太さは維持。
・投稿末尾に関連記事を最大10件表示。同カテゴリーの新着を優先し、足りなければほかの新着で補完。
  公開済み通常投稿のみ。現在の記事とパスワード保護された関連記事は除外。記事が少なければ10件未満。
  パスワード保護中の本文では関連記事を表示しません。固定ページには関連記事を表示しません。
・日付、投稿者、タグ・カテゴリーのメタラベル、前後記事ナビは出力しません。
  パンくずにはカテゴリー名と親カテゴリーを表示します。
・WordPress標準のコメント・記事内改ページ・固定ページ・パスワード保護・管理バーに対応。
  コメントを使わない場合は「設定 → ディスカッション」と各投稿のコメント設定を無効化。
  コメント内の投稿者・日時はWordPress標準表示です。記事本文やウィジェットに手動で入れた情報はそのまま表示。
・キーボード対応メニュー、Escapeで閉じる、スキップリンク、フォーカス表示。

注意
テーマ切り替え前にバックアップを取り、広告・既存プラグインとの表示を確認してください。
テーマの直接編集は更新時に上書きされるため、継続的なカスタマイズには子テーマを推奨します。
広告スクリプトは広告サービスが案内するコードを利用してください。
カスタムHTMLのscript保存可否はWordPressの権限・マルチサイト設定に従います。
